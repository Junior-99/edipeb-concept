# Edipeb Ventures independent concept

Six-page React wholesale enquiry concept. This is not an official or commissioned business site and takes no orders or payments.

## Development

Run `npm ci`, `npm run dev` and `npm run build`. Static output is `dist`, using relative assets for free GitHub Pages hosting.

## Actual features

Commodity selection persists across routes. Buyer form validates quantity, units, destination, date and bounded specifications. Local workspace supports search, status filtering, notes, JSON exports and persistent records. Optional shared concept inbox requires explicit demonstration consent. Authenticated creator dashboard uses Supabase with server-enforced membership policies. No privileged key or password is included. Approved creator must register and verify their own email.

Original Three.js yam crate rotates with scroll and pointer drag. WebGL pauses offscreen and respects reduced motion. Generated produce still life is labelled illustrative and never described as business stock.
